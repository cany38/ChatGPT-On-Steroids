How to connect ChatGPT

About two minutes, once. After that this panel only shows what ChatGPT does on this computer.

  1. Copy your connector URL

    This is the address ChatGPT uses to reach this computer. It contains a secret key, so treat it like a password.

    The URL appears here after Cloudflare setup.

  2. Add it in ChatGPT

    1. Open ChatGPT > Plugins (chatgpt.com/plugins).
    2. Press Add (top right) and choose the custom MCP server option.
    3. Name: ChatGPT On Steroids. Under Connection keep Server URL selected and paste the address you copied.
    4. Open the Authentication dropdown and choose No authentication (see the red note below).
    5. Tick I understand and want to continue, then press Create as a plugin. ChatGPT validates the connector by calling cgt_ping.
    Important: set Authentication to No authentication. ChatGPT picks OAuth by default, and with OAuth the connector fails with [API_CLIENTS_ERROR] Server does not support automatic registration. Choose plain No authentication, not "OAuth or no authentication". With it selected the Advanced OAuth settings disappear, so there is nothing else to fill in. This form has no API Key option, so start the server without CGT_TOKEN; the secret inside the URL is what protects it.

  3. Try it in a chat

    Start a chat and ask: What's in C:\Users\me\Desktop? or Run the cgt_ping tool. The activity table fills as calls arrive, and the top of the panel turns to ChatGPT connected.

  4. Day to day

    • Keep the server open. The Cloudflare relay reconnects on its own after a restart.
    • Writes, deletes and commands run right away, anywhere your user account can reach. Each call lands under Activity.

  5. If something is off

    • "Server does not support automatic registration": Authentication is on OAuth. Set it to No authentication.
    • ChatGPT cannot validate the connector: the relay is offline. Press Restart tunnel and check the panel.
    • Connector offline in ChatGPT: start this server, then try again. The URL stays the same.
    • 401: the server was started with CGT_TOKEN, but this ChatGPT form cannot send a token. Remove CGT_TOKEN and restart the server.
    • Unknown tool: remove and re-add the connector, ChatGPT caches the tool list.
